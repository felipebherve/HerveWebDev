# HerveWebDev

🇧🇷 Português · 🇺🇸 [English](README.md)

Este é meu espaço pessoal onde vou atualizando meu primeiro HTML e CSS.

🔗 **Site publicado:** [felipebherve.github.io/HerveWebDev](https://felipebherve.github.io/HerveWebDev/)

## Em que momento eu fiz isto

Meu primeiro projeto publicado, feito em **2023** durante a etapa autodidata de HTML e CSS ([`04_Autodidata_HTML_CSS_JS_Git`](https://github.com/felipebherve/html-css-js-estudos)). É um lugar com o meu nome onde coloquei o que estava aprendendo, e usei o projeto para praticar Git e GitHub: criar o repositório, fazer commits e publicar o site com o GitHub Pages.

## O que aprendi

Estrutura HTML, layout com CSS, organização de um site com várias páginas com estilos, imagens e arquivos compartilhados, e o fluxo do Git: `init`, `add`, `commit`, `push` e GitHub Pages.

## Como ver

Abra o site publicado acima ou abra o `index.html` no navegador. Não é preciso instalar nada.
