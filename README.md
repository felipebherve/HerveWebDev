## Where I was when I made this

My first published project, made in **2023** during my self-taught HTML and CSS stage ([`04_Autodidata_HTML_CSS_JS_Git`](https://github.com/felipebherve/html-css-js-estudos)). It's a place with my name on it where I put what I was learning, and I used it to practice Git and GitHub: creating the repository, committing and publishing the site with GitHub Pages.

## What's on the site

| Page | What it is |

| `index.html` | Home page ("Study Space") |
| `Portifolio.html` | Portfolio page |
| `Skills_And_Expertise.html` | My skills |
| `Blog&Articles.html` | A blog/articles page |

## What I learned

HTML structure, CSS layout, organizing a multi-page site with shared styles, images and assets, and the Git flow: `init`, `add`, `commit`, `push` and GitHub Pages.

## How to view it

Open the live site above, or open `index.html` in your browser. There is nothing to install.
